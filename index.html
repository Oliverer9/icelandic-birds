Birds of Iceland: accessibility project

The same one-page website about Icelandic birds, built twice by an AI agent from the same prompt: once on its own, and once with an accessibility skill. Both were tested with automated tests, a keyboard, a screen reader and zoom.

Main task: Search for Whimbrel, open it, save it and sign up.

  • Project A: AI without the skill

    Built from the prompt alone and not changed by hand.

  • Project B: AI with the accessibility skill

    Built from the same prompt, following the skill and spec. Fixed until all tests pass.

  • Report

    Test results for A and B, the agent and div experiment, and what testing by hand found.
